# 领域资料

河湟非遗体验传播授权把**非遗项目、传承人允许展示的范围、体验场次、材料包、口译修订、青年作品与媒体用途**建立成可追查的关系网络。

## 身份与素材去重

- 外部主体（传承人、体验者、媒体、青年作者）一律使用不含真实身份信息的引用编号（`*_ref`）。
- 交换时间采用带偏移量的 ISO 8601 字符串；无时区时间在入口即被拒绝，保证到期比较无歧义。
- 原始材料不落库，只保存受控引用或 `sha256` 摘要。
- **媒体素材以 `sha256` 为唯一身份**。两家媒体分别上传同一段视频，系统归并为同一 `media_asset`，各自留下一条 `media_upload`（含其声称的依据 `claimed_basis`），许可只挂在素材身份上——重复影像不会产生第二份许可。

## 可独立变动的授权边界

一次分发必须同时满足以下边界，任一不满足即 `blocked`：

1. **媒体许可**：被授权媒体与实际发布方一致、用途在授予范围内、未撤回、当前时间在有效期内。到期是纯时间推导，不改动许可记录。
2. **传承人边界**：用途在其 `allowed_scopes` 内；肖像可独立拒绝。
3. **完整工序**：素材若含完整工序，需要传承人 `full_process_allowed` **且**许可 `covers_full_process`；否则关键工序只公开 `public_summary`，`restricted_detail` 仅馆员可见。
4. **体验者肖像同意**：逐人核对，状态为 `granted / denied / withdrawn`，且同意范围需覆盖该用途；任一人不满足即拦截。
5. **青年作品、材料包**：各自保留独立的允许用途范围。

## 口译修订

口译以 `translation_units` 保存：同一 `unit_ref` 的每个 `revision` 都**同时包含原文与译文**，改动保持对应，并记录 `change_note`。

## 到期、撤回与事实保留

- `GET /staff/takedowns` 列出仍在发布但当前必须下线的报道与展项及原因；`POST /staff/takedowns/apply` 执行下线并写 `taken-down` 判定流水。
- 撤回许可或体验者肖像同意后，相关用途自动进入下线清单，分发闸门继续阻止。
- **活动发生过的事实不消失**：场次、上传记录、许可历史与判定流水均保留；公众端对已下线用途返回 `410 Gone`，但场次记录仍可查。

## 视图分离

- 公众（`/public/*`）只接触获准说明：项目摘要、工序摘要、场次事实、当前 `allowed` 的用途；不出现体验者、内部材料与许可细节。
- 馆员（`/staff/*`）从任一素材经 `/staff/assets/{ref}/trace` 可查清：上传媒体、项目、场次、传承人、体验者、青年作品、材料包、口译修订、许可、用途及其实时判定。

`contracts/entities.json` 中的字段名称属于稳定接口约定，运行时数据文件位置由 `DATABASE_PATH` 决定。
